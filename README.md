# c40

Keenon C40 청소 로봇의 **원클릭 층 전환 앱** 개발 프로젝트.

층을 수동으로 옮긴 뒤 "지도 관리 앱 → 층 변경 → 청소 앱 → 로컬라이즈"로 이어지는 절차를
"층 선택 → 지도 전환 → 위치 지정 → 인식 확인 → 청소 시작" 한 번의 조작으로 줄이는 것이 목표다.

## 문서

- [docs/01_robot_investigation.md](docs/01_robot_investigation.md) — 앱 구성, 제어부 통신 경로, 시스템 정보, 지도/위치 데이터, 동작 로그 조사
- [docs/02_clean_app_internals.md](docs/02_clean_app_internals.md) — 청소 앱 디컴파일 분석: 층 전환·위치 지정의 실제 동작, CoAP/HTTP 인터페이스
- [docs/03_app_design.md](docs/03_app_design.md) — 원클릭 앱 설계안과 개발 단계

01 문서의 층 전환 관련 가정 일부는 02 문서에서 수정되었다. 02·03 을 기준으로 본다.
