# c40

Keenon C40 청소 로봇의 **원클릭 층 전환 앱** 개발 프로젝트.

층을 수동으로 옮긴 뒤 "지도 관리 앱 → 층 변경 → 청소 앱 → 로컬라이즈"로 이어지는 절차를
"층 선택 → 지도 전환 → 위치 지정 → 인식 확인 → 청소 시작" 한 번의 조작으로 줄이는 것이 목표다.
